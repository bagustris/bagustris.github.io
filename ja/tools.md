## ツール・ツールキット

### [Nkululeko](https://nkululeko.readthedocs.io)

音声から話者の特性（感情、年齢、性別、病的音声など）を予測する、高水準の Python フレームワークです。1 つの設定ファイルで機械学習パイプライン全体を実行できます。

- 📖 ドキュメント: [nkululeko.readthedocs.io](https://nkululeko.readthedocs.io)
- 💻 ソースコード: [github.com/felixbur/nkululeko](https://github.com/felixbur/nkululeko)

### [Speechain](https://bagustris.github.io/speechain)

音声処理・分析のためのツールとユーティリティです。データ準備、特徴量抽出、学習の補助など、私の音声実験で繰り返し使っているものをまとめています。

- 🌐 サイト: [bagustris.github.io/speechain](https://bagustris.github.io/speechain)
- 💻 ソースコード: [github.com/bagustris/speechain](https://github.com/bagustris/speechain)

### [Sherox](https://github.com/bagustris/sherox)
音声AI推論のための CLI ツールです。学習済みモデルを新しい音声ファイルに対して、リアルタイムでもオフラインでも、ローカルで実行できます。バッチ処理と出力の整形にも対応しています。  
 - 対応タスク: 音声認識、音声合成、話者照合、セグメンテーション、言語識別など  
 - ソースコード: [github.com/bagustris/sherox](https://github.com/bagustris/sherox)  

### [Coughkit](https://github.com/bagustris/coughkit)
咳音の分析と分類のための Python パッケージです。咳の検出、セグメンテーション、カウントを主な対象としています。  
- ソースコード: [github.com/bagustris/coughkit](https://github.com/bagustris/coughkit)

### [Multibench](https://human-ai-lab.github.io/multibench) 
さまざまなタスクとデータセットでマルチモーダルモデルを評価・比較するためのベンチマークフレームワークです。人とAIのインタラクションと実世界での応用に焦点を当てています。  
- 🌐 サイト: [human-ai-lab.github.io/multibench](https://human-ai-lab.github.io/multibench)
- ソースコード: [github.com/human-ai-lab/multibench](https://github.com/human-ai-lab/multibench)

### [PaperRAG](https://bagustris.github.io/paperrag)

研究論文に対する、ローカル実行・CPU対応の検索拡張生成（RAG）ツールです。文献を外部APIに送らずに対話できます。

- 🌐 サイト: [bagustris.github.io/paperrag](https://bagustris.github.io/paperrag)
- 💻 ソースコード: [github.com/bagustris/paperrag](https://github.com/bagustris/paperrag)

### Yomitan-PDF-Viewer 
日本語読解ツール Yomitan などのプラグインに対応した、インストール可能なオフライン PDF ビューアです。完全にオフラインで動作し、注釈、しおり、テキスト検索に対応しています。
- 🌐 サイト: [bagustris.github.io/yomitan-pdf-viewer](https://bagustris.github.io/yomitan-pdf-viewer)
- ソースコード: [github.com/bagustris/yomitan-pdf-viewer](https://github.com/bagustris/yomitan-pdf-viewer)

### Primer2-theme 
2 カラムの Jekyll テーマです。学術・研究サイト向けの静的サイトジェネレーター用で、すっきりとした現代的なデザインに、論文、プロジェクト、ブログ記事のサポートを備えています。
- 🌐 サイト: [bagustris.github.io/primer2](https://bagustris.github.io/primer2)
- ソースコード: [github.com/bagustris/primer2-theme](https://github.com/bagustris/primer2-theme)

## アプリ（PWA）

### Kanji Drills
日本語の漢字を学ぶための Progressive Web App（PWA）です。日本の小学生が漢字を学ぶ方法をまねて、間隔反復とクイズで学習します（音読み・訓読みは扱わず、簡単な単語と文を使います）。  
- 🌐 サイト: [bagustris.github.io/kanji-drills](https://bagustris.github.io/kanji-drills)  

### Kotoba
「言語は単語の集まりである」という考え方に基づく、日本語の語彙学習用 PWA です。5,000 語以上を収録し、間隔反復と例文に対応しています。 

- 🌐 サイト: [bagustris.github.io/kotoba](https://bagustris.github.io/kotoba)  

### JLPT
日本語能力試験（JLPT）に向けて**漢字**と**熟語**を学ぶ PWA です。Kanji Drills に似ていますが、小学生の学び方をまねず、大人の学習者向けになっています。  
- 🌐 サイト: [bagustris.github.io/jlpt](https://bagustris.github.io/jlpt)  

### JED
10 万語以上を収録した日英辞書の PWA です。漢字、筆順、単語、例文を含みます。  
- 🌐 サイト: [bagustris.github.io/jed](https://bagustris.github.io/jed)  

### Wani Kanji
**レッスン**と**復習**を**タイピング**で行い、間隔反復で漢字を学ぶ PWA です。  
- 🌐 サイト: [bagustris.github.io/wani-kanji](https://bagustris.github.io/wanikanji)  

### Onchou  
学習者自身の録音をもとに日本語のピッチアクセントを学ぶ PWA です（データはサーバーに送信されません）。  
- 🌐 サイト: [bagustris.github.io/onchou](https://bagustris.github.io/onchou)
